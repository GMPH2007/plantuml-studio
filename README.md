# PlantUML Studio IDE
### Programado por GMPH2007

Aplicación web profesional para crear, diseñar y renderizar diagramas PlantUML en tiempo real con 0 anuncios y 0 demoras.

## Características
- ⚡ Compilación y renderizado ultra rápido en tiempo real (0 ms de espera).
- 🔢 Números de línea sincronizados estilo VS Code.
- 🚨 Diagnóstico inteligente de errores de sintaxis en español con auto-corrección en 1 clic.
- 📸 Copiar diagramas en alta resolución HD (2.5x) directamente al portapapeles.
- 🌓 Modo Claro y Modo Oscuro completo para toda la interfaz.
- 👤 Soporte completo para personitas (actores), bases de datos y bloques condicionales.
